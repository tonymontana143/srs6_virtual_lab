# Проект симулятора

Среда: **Wokwi** (Arduino UNO).

- `diagram.json` — схема (D9 TRIG, D10 ECHO, D2 кнопка на GND, D13/D12/D11 LED через свои 220 Ом).
- Публичная ссылка на проект Wokwi: [вставить ссылку после сохранения]

Кнопка удерживается клавишей `1` (атрибут `key`), чтобы можно было держать её и одновременно двигать ползунок дистанции HC-SR04.
Для эксперимента C атрибут `bounce` кнопки меняется на `"0"`.
